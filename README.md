<p>App simples com frases motivacionais para inspirar e melhorar o seu dia. Toque em um botão e receba uma nova citação de grandes pensadores.</p>

<h2>✨ Funcionalidades</h2>
<ul>
  <li><strong>Frases Inspiradoras</strong>: Uma coleção de frases motivacionais de diversos autores.</li>
  <li><strong>Gerador de Frases</strong>: Toque no botão "Nova Frase" para receber uma nova citação de forma aleatória.</li>
  <li><strong>Interface Limpa</strong>: Design simples e focado no conteúdo para uma leitura agradável.</li>
  <li><strong>Construído com Práticas Modernas</strong>: Desenvolvido utilizando componentes de arquitetura do Android recomendados pelo Google.</li>
</ul>

<h2>🛠️ Tecnologias Utilizadas</h2>
<p>Este projeto foi construído utilizando as seguintes tecnologias e conceitos:</p>
<ul>
  <li><a href="https://kotlinlang.org/"><strong>Kotlin</strong></a>: Linguagem de programação principal, 100% em Kotlin.</li>
  <li><a href="https://developer.android.com/jetpack"><strong>Android Jetpack</strong></a>:
    <ul>
      <li><strong>ViewModel</strong>: Para gerenciar os dados da UI de forma consciente do ciclo de vida, sobrevivendo a mudanças de configuração (como rotação de tela).</li>
      <li><strong>LiveData</strong>: Para construir um fluxo de dados observável que notifica a UI sobre mudanças nos dados.</li>
      <li><strong>View Binding</strong>: Para interagir com as views de forma segura e concisa.</li>
    </ul>
  </li>
  <li><strong>Arquitetura MVVM</strong>: (Model-View-ViewModel) para separar a lógica de negócio da interface do usuário, tornando o código mais limpo, testável e fácil de manter.</li>
  <li><strong>Recursos de String (<code>string-array</code>)</strong>: As frases e autores são armazenados em arquivos de recursos XML para facilitar a manutenção e a localização (tradução).</li>
</ul>

<h2>🚀 Como Executar</h2>
<p>Para rodar este projeto, você precisará do <a href="https://developer.android.com/studio">Android Studio</a> instalado.</p>
<ol>
  <li>Clone este repositório:
    <pre><code>git clone https://github.com/SEU_USUARIO/Motivaciona-do-dia-App.git</code></pre>
  </li>
  <li>Abra o projeto no Android Studio.</li>
  <li>Aguarde o Gradle sincronizar as dependências.</li>
  <li>Execute o app em um emulador ou em um dispositivo físico.</li>
</ol>
